# Proyecto Front-End JavaScript

Aplicación web desarrollada como proyecto académico del
FP de Desarrollo de Aplicaciones Web (DAW).

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Maquetación web responsive
- Manipulación del DOM
- Gestión de eventos en JavaScript
- Carga y gestión de datos desde archivos JSON
- Interacción dinámica con el usuario sin recargar la página

## Objetivo del proyecto
Proyecto orientado a practicar el desarrollo front-end,
el uso de JavaScript y la estructuración de una aplicación
web sencilla.

## Estructura del proyecto
- `index.html`: estructura principal de la aplicación
- `css/`: estilos de la aplicación
- `js/`: lógica JavaScript
- `data/` o archivos JSON: datos utilizados por la aplicación

## Estado del proyecto
Proyecto académico finalizado.
